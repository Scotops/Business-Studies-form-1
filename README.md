# Business Studies Form One — Accessible Digital Textbook

An offline-capable Accessible Digital Textbook for *Business Studies for Secondary Schools Student’s Book Form One*.

The reader contains one centered, responsive book sheet for each of the source PDF's 48 physical pages. It includes matching printed page numbers, justified text layouts, image descriptions, glossary support, easy-read content, and complete English read-aloud audio.

Open `index.html` to start reading.
